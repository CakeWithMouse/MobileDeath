# Блинопёк — список 2D-ассетов

Основание: [диздок](GAME_DESIGN.md). Визуальное направление: тёплая блинная, дерево, керамика, старая плита, фактурное оформление.

В таблицах перечислены изображения, слои и визуальные состояния. Это не количество файлов: слои можно переиспользовать, а переходы выполнять анимацией.

Готовые исходники хранятся в [`UnityPart/PancakeCooker/Assets/Art/Blinopek`](../UnityPart/PancakeCooker/Assets/Art/Blinopek): `kitchen`, `decor`, `ui` и `visitors`. В каждой группе сохранены реестр и промпты.

Экраны, состояния интерфейса и блюда собираются из отдельных слоёв. Текстуры теста, обе стороны блина, маски покрытия, начинки и сгибы сохраняются независимо. Исходные слои предназначены для сборки анимаций; готовая реализация переходов в этот набор не входит. Названия рабочих зон, ингредиентов и действий в игровую графику не вшиты; обучающие подписи выводятся отдельно во время обучения.

## Блин и тесто

| Ассет | Состав и состояния |
| --- | --- |
| Сырое тесто | Текстура для нанесения пальцем внутри круга сковороды. |
| Поверхность блина | Сырая/недожаренная, готовая, подгоревшая. Поддержать независимое состояние двух сторон. |
| Покрытие и дырки | Маска нанесённого теста: незаполненные участки остаются прозрачными. Дырки должны быть видны и после переноса на тарелку. Дырки формируются динамической маской; отдельный рисунок каждой дырки не нужен. |
| Треугольник | Готовая форма и элементы для показа складывания жестом. |
| Конверт | Готовая форма и элементы для показа складывания жестом. |
| Трубочка | Готовая форма и элементы для показа сворачивания жестом. |
| Ошибочное складывание | Отображение фактического результата жестов, включая неправильную или незавершённую форму. Конкретный набор состояний зависит от реализации жестов. Фактическая форма определяется жестом; готовый рисунок представляет один визуальный образец. |

Состояние прожарки сохраняется при перевороте, переносе и складывании. Покрытие, начинки и сгибы хранятся раздельно: отдельная картинка для каждой комбинации ингредиентов не нужна.

- Пять помощников обозначаются отдельно: каждый покупается для своей начинки. Можно использовать иконку ингредиента с общим значком автоматизации.

- Ручное и автоматическое нанесение используют одни и те же изображения начинки.
- Все порции или весь слой одного типа должны удаляться вместе при использовании инструмента.
- Для теста, переворота, снятия и складывания помощники не предусмотрены.

| Группа | Необходимая графика |
| --- | --- |
| Улучшения обслуживания | Иконки более частого прихода гостей, удлинения дня и улучшения терпения. |
| Улучшения кухни | Иконки ускорения оборудования и направляющих. |
| Помощники | Пять карточек с обозначениями из раздела начинок. Пять вариантов собираются с соответствующей иконкой начинки; состояния общие. |
| Ремонт | Значок неисправности, изображение объекта в карточке ремонта. Если неисправность показывается в сцене — слой повреждения и исправный вариант. Конкретные повреждения сцены — после утверждения каталога ремонта. |

| Категория | Базовый вариант | Покупаемый вариант |

| Пол | Светлые доски. | Терракотовая плитка. |
| Мебель | Простой стол и табуреты. | Тёмный стол и стулья с зелёными сиденьями. |
| Скатерти | Однотонный лён. | Зелёная клетка. |
| Посуда | Кремовая керамика. | Керамика с зелёным узором по краю. |
| Освещение | Простой светильник. | Латунный светильник с абажуром. |
| Предметы на стойке | Керамический кувшин. | Ваза с цветами. |

Всего 16 вариантов оформления: по 1 базовому и 1 покупаемому в каждой из 8 категорий. Один вариант может состоять из нескольких изображений, например стола и стульев.

Для каждого предмета декора нужны вид в сцене и превью для магазина. Превью можно получать из основного изображения. Сменные предметы отделяются от фона. Оба варианта посуды должны сохранять читаемость блина и начинок.

## Анимации и переходы

| Действие | Что нужно показать |
| --- | --- |
| Нанесение теста | Появление теста по движению пальца и сохранение незакрытых участков. Появление по динамической маске. |
| Жарка | Переходы между сырой, готовой и подгоревшей поверхностью. |
| Переворот | Движение блина и смена видимой стороны после нажатия на ручку. Перемещение и смена видимой стороны выполняются кодом. |
| Перекладывание | Перенос блина со сковороды на тарелку. |
| Начинка | Появление намазанного слоя или движение отдельной порции при перетаскивании; автоматическое нанесение помощником. |
| Удаление начинки | Применение инструмента и исчезновение всей начинки выбранного типа. |
| Складывание | Три последовательности: треугольник, конверт, трубочка; результат соответствует выполненным жестам. [Геометрия и правила переиспользования](../UnityPart/PancakeCooker/Assets/Art/Blinopek/kitchen/fold-geometry.json); готовой покадровой анимации нет. |
| Выдача | Передача всего заказа после складывания последнего блина. |
| Посетитель | Появление, уход, смена реакции. Появление, уход и смена слоя выполняются кодом. |

Отдельные покадровые наборы нужны только при выборе покадровой анимации. Перемещение, изменение маски и смена слоёв могут использовать уже перечисленную графику.

## Зафиксированный объём

- 2 игровые зоны: обслуживание и кухня.
- 8 посетителей, по 3 основных реакции — 24 состояния персонажей.
- 3 формы складывания и 3 состояния прожарки.
- 5 начинок: 3 намазываемых слоя и 2 вида порций; иконки всех 5 начинок.
- 5 обозначений помощников начинок.
- 1 кулинарный скребок и его иконка.
- 2 иконки валют.
- 16 вариантов оформления в 8 категориях декора.
- Общий набор интерфейса и анимации из таблиц выше.

Сюжетные предметы, дополнительные реакции для конкретных сцен и изображения конкретных неисправностей добавляются после разработки историй и каталога ремонта. Изображения наборов магазина используют утверждённую графику валют и декора. Общий итог в файлах зависит от разбиения на слои и способа анимации.
