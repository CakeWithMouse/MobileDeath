# Блинопёк — список 2D-ассетов

Основание: [диздок](GAME_DESIGN.md). Визуальное направление: тёплая блинная, дерево, керамика, старая плита, фактурное оформление.

В таблицах перечислены изображения, слои и визуальные состояния. Это не количество файлов: слои можно переиспользовать, а переходы выполнять анимацией.

## Окружение и кухня

| Ассет | Состав и состояния |
| --- | --- |
| Зона обслуживания | Фон помещения, стойка отдельным передним слоем, место посетителя, область выдачи заказа. |
| Рабочая зона кухни | Фон, плита, поверхность сборки, места для ингредиентов и готовых блинов. |
| Сковорода | Основа, ручка для нажатия, рабочая область под блин. Элементы для переворота должны двигаться независимо от фона. |
| Тарелка | Пустая тарелка; блин и начинки размещаются отдельными слоями поверх неё. |
| Ёмкости начинок | Пять различимых ёмкостей или обозначений: масло, варенье, мёд, творог, грибы. |
| Место удаления блина | Обозначение области, куда убирается испорченный блин. |
| Инструмент удаления начинки | Изображение инструмента для применения и иконка для магазина и запаса. Внешний вид инструмента в диздоке не задан. |
| Направляющие | Контур круга теста, отметки трафарета для порций начинки. |

## Блин и тесто

| Ассет | Состав и состояния |
| --- | --- |
| Сырое тесто | Текстура для нанесения пальцем внутри круга сковороды. |
| Поверхность блина | Сырая/недожаренная, готовая, подгоревшая. Поддержать независимое состояние двух сторон. |
| Покрытие и дырки | Маска нанесённого теста: незаполненные участки остаются прозрачными. Дырки должны быть видны и после переноса на тарелку. |
| Треугольник | Готовая форма и элементы для показа складывания жестом. |
| Конверт | Готовая форма и элементы для показа складывания жестом. |
| Трубочка | Готовая форма и элементы для показа сворачивания жестом. |
| Ошибочное складывание | Отображение фактического результата жестов, включая неправильную или незавершённую форму. Конкретный набор состояний зависит от реализации жестов. |

Состояние прожарки сохраняется при перевороте, переносе и складывании. Покрытие, начинки и сгибы хранятся раздельно: отдельная картинка для каждой комбинации ингредиентов не нужна.

## Начинки и помощники

| Начинка | Графика на блине | Обозначения в интерфейсе |
| --- | --- | --- |
| Масло | Слой для намазывания; маска нанесённой области. | Иконка начинки и обозначение её помощника. |
| Варенье | Слой для намазывания; маска нанесённой области. | Иконка начинки и обозначение её помощника. |
| Мёд | Слой для намазывания; маска нанесённой области. | Иконка начинки и обозначение её помощника. |
| Творог | Спрайт порции для перетаскивания и размещения по трафарету. | Иконка начинки и обозначение её помощника. |
| Грибы | Спрайт порции для перетаскивания и размещения по трафарету. | Иконка начинки и обозначение её помощника. |

- Пять помощников обозначаются отдельно: каждый покупается для своей начинки. Можно использовать иконку ингредиента с общим значком автоматизации.
- Состояния помощника: недоступен, доступен для покупки, куплен и включён, куплен и выключен. Общие рамки и значки переиспользуются.
- Ручное и автоматическое нанесение используют одни и те же изображения начинки.
- Все порции или весь слой одного типа должны удаляться вместе при использовании инструмента.
- Для теста, переворота, снятия и складывания помощники не предусмотрены.

## Посетители

| Ассет | На кого требуется |
| --- | --- |
| Вид посетителя у стойки | Каждый уникальный обычный и сюжетный персонаж. |
| Нейтральная реакция | Заказ, диалог и ожидание. |
| Положительная реакция | Удовлетворённый посетитель при выдаче заказа. |
| Отрицательная реакция | Ошибки в заказе, долгое ожидание, требование возврата. |
| Аватар автора отзыва | Изображение соответствующего посетителя; может быть вырезано из основного рисунка. |
| Сюжетные предметы и дополнительные реакции | Только для утверждённых историй и сцен. |

Количество персонажей и сюжетных предметов определяется собственным лором и списком посетителей. Имена, внешность и число персонажей диздоком пока не заданы.

## Интерфейс

| Экран или система | Необходимая графика |
| --- | --- |
| Общие элементы | Панели, кнопки, вкладки, рамки карточек, стрелки, закрытие, подтверждение, отмена, замок, отметка выбора. Состояния: обычное, нажатое, выбранное, недоступное. |
| Стойка и диалог | Облако реплики, кнопки принятия и уточнения, варианты ответа, шкала терпения, значки игровых часов и рабочего дня. |
| Заказ | Панель текста заказа, счётчик блинов, обозначения пяти начинок и трёх форм. |
| Кухня | Выбор ингредиента, выделение активной начинки, обозначение инструмента удаления и счётчик его запаса, переключение между стойкой и кухней. |
| Книга рецептов | Обложка/панель книги, страницы или карточки, вкладки категорий, отметки закрытого рецепта и фирменного блюда. Изображения блюд собираются из графики блинов и начинок. |
| Результат заказа | Общие обозначения чаевых, возврата и оценки. Суммы и реплики выводятся текстом. |
| Итог дня | Панель отчёта, оформление строк доходов и расходов, обозначение прибыли, кнопки покупок, следующего дня и повторного прохождения при неудаче. |
| Магазин развития | Карточка товара, место цены и валюты, состояния «закрыто», «куплено», «установлено», кнопки покупки и установки. |
| Отзывы | Карточка отзыва, элементы отображения оценки и общего рейтинга; аватары переиспользуются. |
| Пауза и настройки | Панель, продолжение, управление звуком, выход. |
| Валюты | Две разные иконки: обычная и премиальная валюта. Их внешний вид и названия ещё не заданы. |
| Реклама за награду | Значок просмотра, панель предложения, изображение награды, состояния загрузки, недоступности и получения награды. |
| Донат | Карточки наборов валюты, изображения платного декора, иконка билета получения рекламной награды без просмотра. |
| Результат покупки | Общие обозначения ожидания, успеха, ошибки и восстановления постоянных покупок. |
| Текст | Шрифт с кириллицей, цифрами и необходимыми символами для интерфейса. |

## Улучшения, ремонт и декор

| Группа | Необходимая графика |
| --- | --- |
| Улучшения обслуживания | Иконки более частого прихода гостей, удлинения дня и улучшения терпения. |
| Улучшения кухни | Иконки ускорения оборудования и направляющих. |
| Помощники | Пять карточек с обозначениями из раздела начинок. |
| Ремонт | Значок неисправности, изображение объекта в карточке ремонта. Если неисправность показывается в сцене — слой повреждения и исправный вариант. |
| Фасад и вывеска | Базовое оформление и каждый покупаемый вариант. |
| Стены и пол | Базовые поверхности и каждый покупаемый вариант покрытия. |
| Мебель и скатерти | Базовые предметы и каждый покупаемый вариант. |
| Посуда | Базовый комплект и каждый покупаемый вариант; рабочая тарелка сохраняет читаемость блина. |
| Освещение | Базовые светильники и каждый покупаемый вариант. |
| Предметы на стойке | Изображение каждого доступного украшения. |

Для каждого предмета декора нужны вид в сцене и превью для магазина. Превью можно получать из основного изображения. Сменные предметы отделяются от фона. Количество вариантов и платных наборов определяется каталогом магазина.

## Анимации и переходы

| Действие | Что нужно показать |
| --- | --- |
| Нанесение теста | Появление теста по движению пальца и сохранение незакрытых участков. |
| Жарка | Переходы между сырой, готовой и подгоревшей поверхностью. |
| Переворот | Движение блина и смена видимой стороны после нажатия на ручку. |
| Перекладывание | Перенос блина со сковороды на тарелку. |
| Начинка | Появление намазанного слоя или движение отдельной порции при перетаскивании; автоматическое нанесение помощником. |
| Удаление начинки | Применение инструмента и исчезновение всей начинки выбранного типа. |
| Складывание | Три последовательности: треугольник, конверт, трубочка; результат соответствует выполненным жестам. |
| Выдача | Передача всего заказа после складывания последнего блина. |
| Посетитель | Появление, уход, смена реакции. |

Отдельные покадровые наборы нужны только при выборе покадровой анимации. Перемещение, изменение маски и смена слоёв могут использовать уже перечисленную графику.

## Объём, который ещё зависит от контента

- Число обычных и сюжетных посетителей, их внешность и уникальные реакции.
- Сюжетные предметы и иллюстрации конкретных историй.
- Число вариантов декора, внешние виды ремонтируемых объектов и платные наборы.
- Внешний вид инструмента удаления и двух валют.

Эти позиции входят в список работ, но их конкретный состав требует согласования. Общий итог в спрайтах до этого не фиксируется.
